Privacy notice

The challenge form is for a non-confidential introduction to the GCL team.

What is collected

The form collects your organisation, name, work email, challenge area, title and summary, plus any optional desired outcome and interest in mentoring. Your consent to being contacted is recorded. No attachments are accepted.

How submissions are used

The GCL team uses these details to review the proposed challenge and contact you about the opportunity. Submissions are stored in a private inbox and are not published in the project gallery.

Access and deletion

The site owner can access, review and permanently delete submissions. To request a correction or deletion, contact the WeSchool GCL representative who shared this website with you and identify your organisation and submission email. This website does not provide public access to submitted challenges.

Please leave out sensitive information

Do not include confidential business documents, passwords, financial account details, personal data about others or information you are not authorised to share. Detailed access requirements and any confidentiality arrangements should be discussed separately with the GCL team.

Basic site operation

The public showcase is hosted on GitHub Pages; GitHub may process visitor IP addresses for security. The challenge form and private inbox are hosted separately on Sites. The site stores a local preference for the 3D experience. Signing in to the private inbox uses the hosting platform’s authentication. Temporary, hashed submission identifiers are used to limit spam; the form does not use advertising trackers.

Student project references

The gallery displays student prototypes and original reference screenshots. Demonstration balances, scores, charts and proposed features are not verified commercial results. Any organisation named in a reference is identified for project context and is not presented as endorsing this website.
